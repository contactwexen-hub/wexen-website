WEXEN WEBSITE — QUICK START

1. Extract the WEXEN-website.zip file.
2. Open the extracted WEXEN-website folder in VS Code.
3. Open index.html in your browser, or use the VS Code Live Server extension.
4. Edit text and links in index.html.
5. Edit colours, spacing and responsive styles in css/style.css.
6. Edit mobile navigation and contact form demo behaviour in js/script.js.

IMPORTANT:
- The contact form is a front-end demo. It does not send messages yet.
- The project concepts are illustrative placeholders, not completed client projects.
- Before publishing, replace sample portfolio concepts with your real work and connect a form service such as Formspree or your own backend.
- The logo emblem is recreated as inline SVG artwork inspired by the reference image.
